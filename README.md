Automated Quiz Generator
  Full-Stack web app that generates flashcards and quizzes based on the input of various format:
- topic;
- text;
- a pdf/txt/docx file.
  Stack:
- Backend: Spring Boot 4.1.0, Java 17, Spring Security (JWT), Spring Mail, Spring AI + Gemini Flash 2.5.
- Frontend: Angular v22.
- DB: MongoDB 6.0.2.
